# 사람 대상 전투 실험 기록

아래는 미실시 양식이다. 자동 스크립트의 결과를 이 표에 사람의 결과처럼 옮기지 않는다.

빌드 / 설정 해시 / 장치 / 날짜 / 조작자 A·B(익명):

## 조건

- F3: 좌우 반전 OFF / ON
- F4: 방어자(P2) 정지 시작 / 중앙 방향 속도 6 시작
- F5: 사람 조작
- 방어자: 이동만 / 모든 행동 허용
- 공격자: 자유롭게 견제
- 역할 교대: 사람이 사용하는 P1/P2 장치를 교대
- 각 시작 조건 10회. F7로 기록을 남기고 화면 녹화를 함께 보관.

## 판단

- 이동만으로 80% 이상 무피격 복귀하는 조건이 반복되는가?
- 공격 유도 → 회피 → 반격의 선택이 실제로 있었는가?
- 상대가 지나가는 동안 반대 방향을 견제할 수 있는가?
- 피격 후 아래 발판에 착지하고 다시 접근할 수 있는가?
- 두 사람은 패배 원인과 다음 경기에서 바꿀 행동을 설명할 수 있는가?

수정 시 한 번에 한 설정만 변경하고 이전값·새값·해결 가설·결과를 기록한다. C 단계 통과 여부는 위 관찰과 영상으로 결정한다.
