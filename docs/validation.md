소스 스모크와 실행 파일 스모크는 가상 SDL 디스플레이·오디오를 사용했다. 자동화된 키 이벤트를 앱 입력→시뮬레이션까지 전달한 테스트에서 회피 종료 뒤 실제 적중도 확인했다.

## 관측값

- 넉백: 피격 다음 14틱에 수평 2.1단위, 15번째 틱부터 일반 제어.
- 지상 무입력 감속: 틱당 1.25, 공중 무입력 감속: 틱당 0.4.
- Y=2에서 105초부터 정지하는 규칙 테스트: 체력 100 → 53.2, 막 종료 Y=1.
- 고정 공격 시점 탐침: 정지 방어자 9/10, 초기 속도 6인 방어자 10/10이 2초 내 중앙에 무피격 복귀. 좌우 반전·슬롯 교대에서 동일. **공격자 자유 대응을 포함한 사람의 성공률이 아니다.**
- 실행 폴더는 약 35.3MB, 123개 파일. `_internal`을 포함한 폴더 전체가 필요하다.

## 환경

- Windows 10 Pro, 10.0.19045, x64
- Intel Core i7-7700 @ 3.60GHz
- NVIDIA GeForce GTX 1050
- 물리 메모리 약 16GiB
- Python 3.12.10 / pygame-ce 2.5.7 / SDL 2.32.10 / PyInstaller 6.16.0
- 내부 렌더링 캔버스: 1280×800, 창 크기에 맞춘 비율 유지 확대/축소

이 환경 정보는 실행 환경 기록이며 **1080p 60FPS 성능 인증이나 최소 사양이 아니다**.

## 아직 수행하지 않은 검증

1. 실물 게임패드 2개 연결·해제·재연결 및 실제 키보드 동시 입력 한계.
2. 실제 오디오 출력 및 창 크기별 가독성의 사람 평가.
3. 지침 6.4의 자유 견제, 회피 후 반격, 역할 교대 플레이·영상 수집.
4. 마지막 15초의 자유 대응 및 네 가지 초기 체력 조합 비교.
5. 전체 수직 맵의 재접근 경로, 공동/분할 화면 가독성.
6. 기준 PC에서 실제 1080p 프레임 지연·20회 재경기 메모리 측정.
7. 최소 3쌍·18경기의 플레이 테스트.

자동 규칙 검증 결과를 재미·게임 밸런스·실물 장치 검증의 완료로 간주하지 않는다. C 단계의 사람 검증 조건이 충족될 때까지 전체 맵 확장은 보류한다.
